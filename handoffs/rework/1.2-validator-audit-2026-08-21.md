# Rework — 1.2 Casepack Validator

Date: 2026-08-21 · Independent audit against current `main` (`174e980`)

## Verdict

PASSING SUITE, INCOMPLETE CONTRACT COVERAGE. The 29-row matrix passes and Riverside is
clean, but important shipped domains are outside the validator's reach. Green output is
therefore weaker than it appears.

## Finding `1.2-RA-001` — obligation rules load but are never validated

Severity: Functional

Evidence:

```text
backend/app/casepack/loader.py:27,89  loads obligation_rules.yaml
rg -n obligation_rules backend/app/casepack/validate.py backend/app/casepack/checks.py
                                      returns zero hits
```

Consequently, nonexistent entity/policy/action references can reach downstream event and
scoring work while `validate_casepack` remains green.

## Finding `1.2-RA-002` — W01 ignores the two new preference shapes

Severity: Data

`backend/app/casepack/validate.py:1063-1071` reads only `defaults_by_archetype` rows and
only rows containing `ideal_value`. Current `preferences/policies.yaml` and
`preferences/services.yaml` nest values under `by_decision` and use `ideal_posture` /
`ideal_tier`. W01 therefore cannot detect placeholder-seeded data in two of five preference
domains.

## Finding `1.2-RA-003` — invalid policy vocabularies lack coherence checks

Severity: Functional

The model only checks that a non-null default belongs to a non-empty options list
(`models.py:454-467`). The validator does not check empty-string or duplicate options,
snake-case option/default keys, or that an obligation's `permissive_value` resolves to a
declared option. A model-level error is also currently surfaced through the broad E00
unreadable-pack path, suppressing other pack findings.

### Required rework

- Add explicit, stable validator codes and paired valid/broken fixtures for all obligation
  references and policy vocabulary rules.
- Make W01 traverse every supported preference schema by semantic fields, not one legacy
  shape.
- Preserve aggregate diagnostics: one invalid policy default must not hide independent
  errors elsewhere in the pack.
- Update the versioned code list, message catalogue, docs, fixture matrix, and changelog in
  the same change.

### Acceptance

The matrix must demonstrate that each new fixture fails on the pre-rework validator and
passes/fails as named after rework. Riverside must remain `0 errors · 0 warnings`, and text
and JSON modes must remain identical.
