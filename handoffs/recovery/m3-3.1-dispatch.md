## Required components

- `StatusBadge`: exactly Complete, Partly done, Needs attention, Not started; each uses its
  distinct status role triplet.
- `OptionRow`: Pattern A (`●`/`○`) with selected, unselected, disabled, and visible disabled
  reason states.
- `OptionCard`: Pattern B with selected outline/fill/check, unselected state, disabled reason,
  and required accessible labels.
- `DetailTable`/row affordance: clickable rows expose a trailing chevron, first-cell link
  styling, and row-highlight hover using semantic tokens.
- Button and close primitives must fix the four parked 0.3 cosmetic defects: inline-flex
  button sizing, natural-size close control, semantic Cloud-panel surface, and readable
  split-rule options.

Components must use semantic roles only. Adding a token requires a matching `CONTRACTS.md`
entry and is out of scope for this packet unless the existing role set cannot express the
contract. The gallery at `/_dev/components` is a development surface only; it must not claim
student data or scoring.
