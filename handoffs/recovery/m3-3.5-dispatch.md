# M3.5 Components dispatch

Implement the Components runtime surface from the accepted M3 shell and M2 scoped API
boundary. Read modern checkpoint assets, projects, and rollouts, retaining the legacy
estate/deployment snapshot as a compatibility fallback. Expose only registered casepack
choices and labels. Any write must validate `SheetPatchV1` and call
`SimulationService.patch_sheet`; do not add a parallel state store or fabricate fixture
values in the student route.

The frontend packet owns `/components`, the workbench table, selected-component detail
tabs, and a bounded add-component wizard. The wizard may emit `buy_application`; lifecycle
retirement may emit `retire_asset`. Lock, revision, affordability, and uninitialized
states are backend decisions and must be rendered as such.
