## Fairness-fix correctness (highest value) — the exclusion is fair, not amnesty
The exclusion sets `actionable=False` iff `current_round is not None AND
(first_shown_round == current_round  OR  (fire_round is not None and fire_round == first_shown_round))`.
Verified by direct construction of ledger rows through `project_signal_state`:

- **Genuine multi-round miss STILL penalised** (the key fairness test): a signal shown R2,
  actionable, unacted, that fires R4 —
  - scored at R3 (not yet fired): actionable=True, acted_before_fire=False → COUNTS as a miss.
  - scored at R4 (fired, fire_round 4 ≠ first_shown 2): actionable=True → COUNTS as a miss.
  It is not dropped in any round it had a real window. This is the proof the fix is fair.
- **Fired-on-sight (fire_round==first_shown) permanently excluded** in the scored path (R3/R4/R5
  all actionable=False) — correct: it never gave a response window in any round.
- **First-shown-this-round (RULING #2)** excluded only in the round it appears (R3 excluded,
  R4 counts) — per-round, not permanent.
- **Genuine credit preserved**: shown R2, cleared R3, never fired → actionable=True,
  acted_before_fire=True (still credited).
- **Pin-path regression guard**: a fired-on-sight row projected with current_round=None keeps
  actionable=True (unchanged).

**The fired-on-sight exclusion cannot silently drop a real credit.** A fired-on-sight episode
reaches terminal status `fired` at its raise round (compute_status, ledger.py:91-92); on the
following round advance_ledger's open-episode branch (ledger.py:301) is skipped for non-open
episodes, so it can never subsequently be cleared → acted_before_fire is always False for it.
Excluding it therefore removes only a guaranteed zero from the denominator, never a would-be
credit. The exclusion is precisely scoped.

`_signal_responsiveness` (management.py:138-143) filters on `s.actionable`, confirming the
projected flag is exactly the denominator lever.
