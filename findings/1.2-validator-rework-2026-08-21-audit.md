## Functional

### `1.2-VR-001` — an obligation pointing at a policy with no options still validates clean

`check_obligation_references` only checks E26 when `policy.options` is non-empty:

```python
if policy is not None and policy.options and rule.permissive_value not in policy.options:
```

Independent reproduction: copied the valid obligation fixture, removed only the referenced
policy's `options` and `default`, and ran the branch validator:

```text
validate_casepack audit_no_options --json
[]
exit 0
```

The obligation's `permissive_value` therefore points at no declared state, exactly the
dangling-reference case E26 exists to prevent. Legacy compatibility means a policy without
options may load; it does not make an obligation against an absent vocabulary resolvable.
This also breaches the rework acceptance statement that `permissive_value` must be a member
of the referenced policy's options.

Required correction: when an obligation resolves to a policy with an empty options list,
emit E26 with business-language copy explaining that the policy declares no positions.
Add a paired fixture. Keep policies without obligations backward-compatible.

### `1.2-VR-002` — E15 reports a malformed default as an option and points to the wrong field

`check_policy_vocab` appends malformed options and malformed defaults to one list, then
always emits field `<policy>.options` and the option-only E15 message.

Independent reproduction: changed only a valid policy's default to integer `42`:

```text
ERROR E15 Policy client_record_retention
Lists an option '42' ...
Fix: ... remove it from 'client_record_retention'.
Field: client_record_retention.options
```

The bad value is `default`, not an option. The field locator and repair instruction are
false, so an author following the validator would edit the wrong field.

Required correction: retain E15 if desired, but carry whether the malformed value came from
`options` or `default`; render the correct field and a default-specific message/fix. Add a
fixture/assertion covering the rendered text and JSON field, not only the code.
