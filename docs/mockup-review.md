# 0.3 Mockup Review

Open the mockups directly from disk:

- `mockups/platform.html`
- `mockups/platform-empty.html`
- `mockups/components.html`
- `mockups/components-detail.html`
- `mockups/components-wizard.html`
- `mockups/rollout.html`
- `mockups/rollout-detail.html`
- `mockups/rollout-locked.html`

They intentionally make no network requests. IBM Plex Sans and IBM Plex Mono are
self-hosted from `frontend/src/styles/fonts/`; no local font package or dev server is
required for the static review path.
